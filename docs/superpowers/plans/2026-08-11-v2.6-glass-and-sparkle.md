# MacCleaner v2.6 — Glass & Sparkle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reskin the entire app in the validated "A's bones, C's blood" design (sidebar + glass + mono digits + cyan accent, adaptive light/dark), add bulk selection and live clean progress, replace the plain menu bar menu with a rich popover, ship Sparkle check+prompt auto-updates via an embedded XCFramework and a release-generated appcast, scope the dynamic scanners to the selection, and release 2.6.0.

**Architecture:** All visual language lives in a new `DesignSystem.swift`; views consume it and never hardcode style. The window swaps `TabView` for `NavigationSplitView`. Sparkle embeds as a prebuilt XCFramework fetched+checksummed by `build.sh` (no SPM/Xcode migration), guarded by a `SPARKLE_DISABLED` compile flag so offline dev builds still compile. The appcast is a single-item XML generated by `release.yml`, signed with an EdDSA key from repo secrets, uploaded as a release asset at the stable `releases/latest/download/appcast.xml` URL. One engine change only: `collect_targets` selection hints.

**Tech Stack:** SwiftUI (macOS 13 floor), swiftc via `app/build.sh`, Sparkle 2.9.5 XCFramework, Python 3 stdlib engine, GitHub Actions.

## Global Constraints

- **macOS 13 API floor for ALL Swift code:** no `.snappy`/`.bouncy` animations, no `symbolEffect`, no `Observable` macro — use `.spring(response:dampingFraction:)`/`.easeOut`, `withAnimation`, `ObservableObject`. `NavigationSplitView`, `MenuBarExtra(.window)`, `.ultraThinMaterial`, `contentTransition(.numericText())` are all 13-safe and allowed.
- `app/build.sh` stays a bare `swiftc` build — no Xcode project, no SPM. It must keep compiling with NO network and NO Sparkle cache (the `-DSPARKLE_DISABLED` path).
- Engine: single-file stdlib-only `cleaner.py`; no `X | None` annotations; JSON contract untouched (scanner scoping changes no output shapes); all 232 existing tests stay green.
- Never run `install.sh`. Never `killall MacCleaner` if an instance was already running when the task started (`pgrep -x MacCleaner` first) — the user's real app is live. Visual spot-checks launch `build/MacCleaner.app` ONLY when no instance is running; otherwise capture is deferred and the report says so.
- The committed `MacCleaner.app` bundle is rebuilt ONLY in Task 10 (version sweep) — intermediate tasks never commit bundle changes.
- Sparkle pinned at **2.9.5** (`https://github.com/sparkle-project/Sparkle/releases/download/2.9.5/Sparkle-2.9.5.tar.xz`); its SHA-256 is computed once in Task 7 and hardcoded into `build.sh`.
- Secrets: the EdDSA private key is never committed, never printed, never echoed into logs — it moves file→`gh secret set`→deleted, exactly like the v2.4 cert flow.
- Every view change must be verified in BOTH light and dark appearances (screenshots via `screencapture` of the launched build when permitted).
- Commit after every task; run the full unit suite before each engine-touching commit.

```python
def collect_targets(config, all_categories=False, categories=None, target_ids=None):
    """Static targets plus dynamic scanner targets.

    categories/target_ids are optional SELECTION HINTS from the CLI
    invocation (--category / --targets): when a hint proves a scanner's
    output can't be selected, the scanner is skipped — a targeted
    `clean --targets npm-cache` shouldn't pay two simctl calls and a /tmp
    walk (popover one-click clean latency, v2.6). Hints never widen
    anything: enabled_categories still gates as before, and hints=None
    behaves exactly like pre-2.6."""
    targets = get_targets(config, all_categories=all_categories)
    enabled = set(ALL_CATEGORIES) if all_categories else set(config["enabled_categories"])

    def _wanted(cat, prefix):
        if cat not in enabled:
            return False
        if categories is not None and cat not in set(categories):
            return False
        if target_ids is not None and not any(str(t).startswith(prefix) for t in target_ids):
            return False
        return True

    if _wanted("tmp", "tmp-"):
        targets += tmp_to_targets(scan_tmp_artifacts(config))
    if _wanted("simulators", "simulator-"):
        targets += scan_simulator_targets(config)
    return targets
```
